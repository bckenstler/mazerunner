The task

One image, one continuous drag from the cyan badge to the amber one. Most maze benchmarks are discrete — the model steps between grid cells or emits move tokens. Here it has to draw its route as a stream of coordinates, and the stroke either threads the corridor or it doesn't. A person does this without thinking.

Run it

git clone https://github.com/bckenstler/mazerunner && cd mazerunner
uv sync && uv run pytest -q            # 255 tests, no network
uv run mazerunner run --config configs/providers.example.json \
    --dataset datasets/v1/dev --mazes-file evals/dev-eval-100.txt --trials 8

Full traces for every attempt in this study are in the release assets; the hidden test split ships encrypted.
