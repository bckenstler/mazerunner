The task

The model gets one image and must return a single drag path — an ordered list of coordinates from the cyan start badge to the amber goal. Most maze benchmarks are discrete: grid cells, move tokens. This one asks the model to draw, and the whole path has to stay inside the corridor. Version 2 is a difficulty ladder: eight maze families at four sizes, plus warped twins of the four grid families, so the same maze can be made bigger or bent and the cost of each read off directly.

Leaderboard

192 mazes × 4 attempts · 48 equally weighted cells (12 maze types × 4 sizes) · 95% CIs resample tasks within cells

#model pass@1pass@4 L1L4L4 warped

L1 is the original v1 medium size; an L4 route has 3.4× the turns, in narrower corridors. Warped cells exist for the four grid families (rectilinear, braided, pipes, island). An attempt the model never answered, after two tries at a 10- or 30-minute budget, counts as a fail (32 of 7,776, all at the longest routes).

Thinking longer

Each model at a second effort setting, on the 24 L3/L4 cells only · gains are paired by task, with 95% CIs

modelsettingL3/L4 pass@1 gainmedian output

GPT xhigh and Claude max run with a 30-minute budget per call. Claude max is one attempt per maze (96 calls); the rest are four. Gemini 4 Argon thinks by default, and its higher settings had no effect through the serving gateway, so its comparison runs the other way: default against thinking switched off.

What the study found

From 7,776 attempts, re-scoring at other tolerances, and a per-attempt failure classification. The full argument with caveats is in the study.

Run it

git clone https://github.com/bckenstler/mazerunner && cd mazerunner
uv sync && uv run pytest -q            # offline, no API keys
uv run mazerunner run --config configs/providers.v2.json \
    --providers gpt6-astra --dataset datasets/v2/test \
    --trials 4 --run-id myrun --order-seed 20261028
uv run mazerunner merge --runs 'results/myrun-*' --out results/myrun/merged
uv run mazerunner board --attempts results/myrun/merged/attempts.jsonl

Full traces for every attempt in this study are in the release assets. v1 (1,000 tasks, July 2026) remains available at the v1.0.0 release.
