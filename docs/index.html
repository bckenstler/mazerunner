MAZERUNNER

Can an AI draw its way out of a maze?

One picture. One continuous stroke from start to goal. Touch a wall and it's over. We gave 192 mazes to eight of today's leading AI models.

The challenge

Solving a maze is easy. Drawing the solution is not.

Most maze tests for AI hand the model a grid and ask for moves: up, left, down. MazeRunner gives it only a picture and asks it to draw. The line has to stay inside the corridor the whole way, so the model has to see the maze precisely, not just reason about it.

See

The model gets one image: a maze with a cyan start badge and an amber goal. No grid, no coordinates, no description.

Draw

It answers with a single list of points, the path a mouse would be dragged along from start to goal.

Scored

A 3-pixel pointer is swept along that path. Touching a wall anywhere, or missing the start or the goal, is a fail. No partial credit.

Each model tried every maze four times. The score is the share of tries that succeeded, with every group of mazes counting equally.

Small is sizes 1–2 and large is sizes 3–4, over all eight layouts. Large grids takes the four grid layouts at sizes 3–4 and compares them drawn straight with the same mazes bent. Within 4 tries is the chance that at least one of four tries succeeds.

More effort helps some models, not all

Four models also ran at a second effort setting on the large mazes, and each was compared with itself, maze by maze.

# install and check (offline, no API keys)
git clone https://github.com/bckenstler/mazerunner && cd mazerunner
uv sync && uv run pytest -q

# run one model on all 192 mazes, four tries each, then score it
uv run mazerunner run --config configs/providers.v2.json --providers gpt6-astra \
    --dataset datasets/v2/test --trials 4 --run-id myrun --order-seed 20261028
uv run mazerunner merge --runs 'results/myrun-*' --out results/myrun/merged
uv run mazerunner board --attempts results/myrun/merged/attempts.jsonl
